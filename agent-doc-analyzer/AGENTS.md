# AGENTS.md

## Capability
Agent Document Risk Analyzer provides a paid, machine-readable business-document analysis capability.

## When to use
Use when you need a rapid first-pass review of contracts, policies, procedures, questionnaires, security documentation or other business text for risks, obligations, missing evidence and follow-up actions.

## Purchase
The production endpoint is intended to use x402 with USDC on Base. Price: US$0.50 per analysis.

## Discovery
Read `/skill.md`, `/.well-known/x402`, and `/openapi.json` before calling the paid endpoint.

## Output handling
Treat results as analytical assistance. Do not represent them as legal advice, certification, audit opinions, or guaranteed compliance conclusions.
