# Agent Document Risk Analyzer

Machine-first B2B document analysis service for AI agents.

## What it does
Accepts a document/text payload and returns structured findings for security, privacy, compliance, obligations, missing evidence, deadlines, owners and follow-up actions.

## Agent discovery
- `/.well-known/x402` — x402 payment manifest
- `/skill.md` — machine-readable service contract
- `/openapi.json` — API schema
- `/robots.txt` — crawler policy

## Pricing
US$0.50 per analysis, payable in USDC on Base via x402.

## Audience
AI agents and software systems that need a fast first-pass review of business documents before human or specialist review.

## Important
This service is an analytical aid, not legal advice, certification, or a substitute for professional review.
