Does EvidenceCheck certify a vendor?

No. It is a first-pass due-diligence workflow. Public signals are signals, not proof of certification, compliance or security. Material findings should be verified by the responsible team.

Is this a penetration test or vulnerability scanner?

No. The service is deliberately bounded. It focuses on observable public signals, evidence extraction and verification gaps; it is not an authorized penetration test.

Why pay with USDC?

The machine endpoints use x402 so compatible software and AI agents can pay per request without a traditional subscription flow. Settlement is configured for USDC on Base.

Can an AI agent use it without a human interface?

Yes. The service publishes OpenAPI and agent-oriented discovery metadata. The machine API returns structured JSON designed for downstream workflows.
