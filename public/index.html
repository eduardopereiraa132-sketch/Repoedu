FAQ

What buyers should know.

Does EvidenceCheck perform a penetration test?

No. It reports observable public signals and evidence gaps. It is a first-pass evidence tool, not a penetration test, vulnerability scanner, certification audit or legal opinion.

Why pay per request?

It fits automated workflows. An agent can call only the capability it needs instead of paying for a large subscription before proving value.

What does the vendor preflight actually tell me?

It summarizes public signals, checks and gaps and gives concrete follow-up areas. It also states its limitations so public evidence is not mistaken for verified assurance.

Can an AI agent use it directly?

Yes. The service exposes machine-readable API definitions and structured JSON responses intended to be composed into larger workflows.
