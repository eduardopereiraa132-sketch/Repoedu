Developer-first

Built to be discovered and called by agents.

HTTP API, structured outputs and machine-readable service descriptions. Payments are handled at the request layer using x402.

curl -X POST https://YOUR-SERVICE/v1/web-extract \ -H 'content-type: application/json' \ -d '{"url":"https://example.com"}'

The public endpoint returns a payment requirement when payment is needed, then returns the requested result after settlement.

Why this exists

Give an AI agent evidence it can act on.

The product is deliberately narrow: public evidence in, structured evidence out. That makes it easier to integrate into procurement, security review, research and due-diligence workflows.

EvidenceCheck · Public-information automation · Not a security certification or legal opinion. Outputs are evidence signals and should be validated for consequential decisions.
