# Client Intake — PDF / Excel Data Cleanup

## Required

- File(s) to process
- Desired output: XLSX / CSV / Google Sheets
- Deadline
- Expected currency/date format
- Definition of a duplicate, if business-specific

## Optional

- Example of the desired final report
- Column mapping
- Known exceptions
- Totals that should reconcile

## Confirmation before work

> I will transform the supplied files into a clean, structured dataset and run consistency checks before delivery. This is data transformation/quality work, not accounting, tax, legal or financial advice. If a business rule is ambiguous, I will flag it instead of silently guessing.

## Internal QA checklist

- [ ] Original files preserved
- [ ] File/page/row counts recorded
- [ ] Extraction completed
- [ ] Headers normalized
- [ ] Dates normalized
- [ ] Currency/numeric fields validated
- [ ] Duplicates reviewed
- [ ] Missing values reviewed
- [ ] Totals reconciled where possible
- [ ] Exceptions separated/flagged
- [ ] Output opened and checked
- [ ] Final response explains what changed
